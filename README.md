# The Long Roast

One line roasting my own AI agent, Muse: asked for a single line, it spun up five subagents, wrote a status file, scheduled a retry cron, and still asked me to confirm the plan it had already executed.

`main.py` writes the roast to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
